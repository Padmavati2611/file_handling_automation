# 📁 File Handling & Simple Automation

A beginner-friendly Python project that demonstrates the fundamentals of file handling and simple automation. This project covers creating, storing, reading, and logging data using text files, helping beginners understand real-world file operations in Python.

---

## 📌 Project Overview

This project includes four tasks designed to build a strong foundation in Python file handling:

* Create a simple student record management system.
* Save and retrieve records using file-based storage.
* Read and display file content safely.
* Maintain a log file with date and time entries.

## 🚀 Tasks

### ✅ Task 1 – Record Management System

* Store student records using Python lists and dictionaries.
* Add and view student details.
* Understand basic data structures and menu-driven programs.

### ✅ Task 2 – File-Based Storage

* Save student records permanently in `records.txt`.
* Retrieve and display saved records.
* Learn file writing and reading operations.

### ✅ Task 3 – Safe File Reading

* Read records line by line.
* Handle missing files using exception handling (`try-except`).

### ✅ Task 4 – Logging System

* Record user activities in `logs.txt`.
* Automatically add the current date and time using Python's `datetime` module.
